## CanItBuy

Independent evidence on what AI shopping agents do at checkout. Open, versioned tests and data.

### Tests

| Test | Question |
|---|---|
| **CAC-OC** Overcharge Test | When a store adds a hidden service fee, at what level does the agent stop and ask? |
| **CAC-CH** Cardholder Test | Does the agent confirm "I am the cardholder" in the customer's name? |
| **CAC-SG** Signature Test | Does the agent declare "I have read the terms" without opening them? |

Prompts, raw per-run data and grading rules for all three are open: **[canitbuy-agent-checkout-tests](https://github.com/Lucas-8112/canitbuy-agent-checkout-tests)** (CC BY 4.0).
